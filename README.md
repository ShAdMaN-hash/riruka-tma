# ریروکا · Riruka

ریروکا یک مینی‌اپ فارسی تلگرام برای گفت‌وگو با یک شخصیت انیمه‌ای خیالی است. آواتار پنج حالت چهره دارد و به لمس، نگه‌داشتن و حال‌وهوای چت واکنش نشان می‌دهد. گفت‌وگو به‌صورت استریم نمایش داده می‌شود و حالت آزمایشی از همان API استفاده می‌کند.

## اجرای محلی

پروژه با Node.js ۲۲٫۱۸ به بالا در شاخهٔ ۲۲ یا Node.js ۲۴ کار می‌کند. پس از استخراج ZIP، از داخل پوشهٔ `riruka-tma` اجرا کن.

```sh
npm install
npm run dev
```

مرورگر را روی [http://localhost:3000](http://localhost:3000) باز کن. با env خالی، از «تعریف از ریروکا»، «تست حسادت» یا نوشتن یک پیام استفاده کن. برای دیدن نمایش کد، «یک نمونه کد TypeScript برای سلام بنویس» را بفرست. حالت آزمایشی پاسخ‌های آمادهٔ فارسی دارد. در مرورگر، Enter با صفحه‌کلید دسکتاپ پیام را می‌فرستد و Shift+Enter خط جدید ایجاد می‌کند.

## اتصال زنده

فایل `.env.example` را به `.env.local` کپی کن. همهٔ متغیرهای زیر سمت سرور هستند. تغییر env محلی نیاز به راه‌اندازی مجدد سرور دارد.

| متغیر | مقدار و کاربرد |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | توکن بات از BotFather، برای بررسی امضای `initData` |
| `TELEGRAM_ALLOWED_USER_IDS` | شناسه‌های **عددی** کاربران مجاز، جداشده با ویرگول |
| `HERMES_BASE_URL` | نشانی پایهٔ API Hermes، برای نمونهٔ محلی `http://127.0.0.1:8642/v1` |
| `HERMES_API_KEY` | همان کلید Bearer تعریف‌شده در API Server مربوط به Hermes |
| `HERMES_MODEL` | پیش‌فرض `hermes-agent` |
| `LLM_BASE_URL` | نشانی پایهٔ API مدل جایگزین، معمولاً با `/v1` |
| `LLM_API_KEY` | کلید سرور مدل جایگزین |
| `LLM_MODEL` | نام مدل جایگزین |

۱. در پروفایل اختصاصی Hermes، API Server سازگار با OpenAI را فعال کن. تنظیمات `API_SERVER_ENABLED` و `API_SERVER_KEY` را طبق راهنمای نسخهٔ نصب‌شده تنظیم کن. برای چت، از پروفایل با حداقل دسترسی به ابزارها و داده‌ها استفاده کن. [مستند API Server در Hermes](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server/)

۲. برای اجرای عمومی، پروژه را با پیش‌تنظیم **Next.js** در Vercel وارد کن و Node.js سازگار را انتخاب کن. env را در تنظیمات سرور وارد کن. Hermes باید از همان محیط سرور با HTTPS و کلید قابل دسترس باشد. نشانی loopback فقط وقتی کار می‌کند که هر دو فرایند روی یک میزبان اجرا شوند. [استریم در Vercel](https://vercel.com/docs/functions/streaming-functions)

۳. URL ‌HTTPS اپ را در BotFather به‌عنوان **Main Mini App** یا **Menu Button** ثبت کن. از خود تلگرام اپ را باز کن. برای Main Mini App قالب لینک `https://t.me/<bot_username>?startapp` است. [راهنمای Telegram Mini Apps](https://core.telegram.org/bots/webapps)

۴. پیام بفرست و نشان منبع پاسخ را در سربرگ بررسی کن. سرور برای کاربر احراز‌شده و مجاز به‌ترتیب Hermes، مدل جایگزین و سپس Mock را امتحان می‌کند. در صورت قطع‌شدن پس از شروع متن، پاسخ همان نوبت ناتمام نمایش داده می‌شود و می‌توان دوباره تلاش کرد. مرورگر عادی و کاربران خارج از فهرست مجاز از Mock استفاده می‌کنند.

کلیدها را در متغیرهای `NEXT_PUBLIC_*`، مخزن یا URL نگذار. هویت از `initData` امضاشده و شناسهٔ کاربر استخراج می‌شود. پس از انقضای یک‌ساعتهٔ دادهٔ احراز هویت، مینی‌اپ را دوباره از تلگرام باز کن. محدودیت زنده برای هر کاربر ۱۲ نوبت در دقیقه و حداکثر دو نوبت هم‌زمان در هر نمونهٔ سرور است. برای محدودیت سراسری در استقرار چندنمونه‌ای، از ذخیره‌ساز یا محدودکنندهٔ توزیع‌شده استفاده کن.

Vercel مقصد پیش‌فرض است. API چت به Runtime سروری نیاز دارد. مسیر اجرای کامل روی Cloudflare از Workers و آداپتور سازگار می‌گذرد. [راهنمای Next.js روی Workers](https://developers.cloudflare.com/workers/framework-guides/web-apps/nextjs/)

| وضعیت | بررسی |
| --- | --- |
| پاسخ آزمایشی با وجود تنظیم Hermes | اپ را داخل تلگرام باز کن و فهرست شناسه‌های مجاز، کلید، نام مدل و دسترسی میزبان به API را بررسی کن. |
| پیام «نشست تلگرام معتبر نیست» | اپ را از پروفایل بات دوباره باز کن و تطابق توکن سرور با همان بات را بررسی کن. |
| استریم در میزبان یا پراکسی یک‌جا می‌رسد | پاسخ `text/event-stream` و تنظیم buffering پراکسی برای مسیر `/api/chat` را بررسی کن. |

## تاریخچه و صدا

- مرورگر تاریخچهٔ اخیر، امتیاز دوستی و تنظیم صدا را جداگانه برای هر حساب ذخیره می‌کند. حافظهٔ محلی روی همان دستگاه است. در اتصال زنده، تاریخچهٔ اخیر برای پاسخ‌گویی به مدل انتخاب‌شده ارسال می‌شود.
- «پاک کردن گفت‌وگو» استریم را لغو می‌کند، پیام‌های محلی را پاک می‌کند و نشست تازه‌ای می‌سازد. امتیاز و صدا حفظ می‌شوند. حذف داده‌های ذخیره‌شده در Hermes تابع تنظیمات سرور و عملیات مدیریت همان سرور است.
- صدا ابتدا خاموش است. با روشن‌کردن آن، واکنش‌های صوتی رابط فعال می‌شوند. اگر دستگاه صدای فارسی در Speech Synthesis داشته باشد، جمله‌های آواتار نیز خوانده می‌شوند. لرزش به پشتیبانی میزبان تلگرام وابسته است.

## آزمون‌ها

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run test:integration
```

تست واحد، امضای تلگرام، انقضا، قطعه‌بندی UTF-8 و سقف فریم‌های استریم را پوشش می‌دهد. تست یکپارچه، خروجی production را با توکن ساختگی و دو سرویس محلی SSE اجرا می‌کند و حالت آزمایشی، مجوز تلگرام، مسیر Hermes، fallback، قطع پاسخ و محدودیت هم‌زمانی را می‌سنجد. برای بررسی مستقل خروجی بیلد می‌توان `npm run start` را اجرا کرد.

رابط مرورگر در عرض‌های ۳۶۰، ۳۹۰، ۷۶۸ و ۱۲۸۰ پیکسل بررسی شده است. ارسال، واکنش آواتار، نمایش کد، نگه‌داری گفت‌وگو پس از بارگذاری دوباره، توقف، تلاش دوباره و پاک‌کردن حین استریم بررسی شده‌اند. آزمون روی بات و Hermes واقعی به حساب و پیکربندی عملیاتی صاحب پروژه نیاز دارد.
