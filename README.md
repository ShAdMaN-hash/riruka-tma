# ریروکا ۳٫۰ · Riruka V3

ریروکا یک مینی‌اپ فارسی تلگرام با استودیوی شخصیت، میز مأموریت و گفت‌وگوی استریم‌شونده است. در نسخهٔ ۳٫۰ علاوه بر شش حالت چهره و عینک، **هالهٔ نوری (Aura)**، **سیستم هدیه به ریروکا**، **سنجاق کردن کارها (Pin)**، **مدیریت گروهی چک‌لیست**، **ارتباط مستقیم میز کار با گفت‌وگو** و **جست‌وجو و خروجی Markdown در گفت‌وگو** اضافه شده است.

مدل از یک بافت تصویری با جزئیات بالا و تغییر شکل زنده روی Canvas ساخته شده است. طراحی از موهای صورتی دوتایی، چتری صاف، چشم‌های شرابی، کلاه سفید، لباس سیاه‌وسفید و عینک تصاویر مرجع استفاده می‌کند. بافت آلفادار در `public/riruka-model.webp` و کنترل حرکت و حالت‌ها در `src/lib/portrait-rig.ts` قرار دارند.

## قابلیت‌های جدید نسخهٔ ۳٫۰ (V3)

- **استودیوی پیشرفته و سیستم هدیه:** امکان دادن هدیه به ریروکا (دونات توت‌فرنگی، عروسک خرگوشی، لاتهٔ ماچا) با دیالوگ‌های اختصاصی، افکت صوتی چندنتی (ملودی شاد) و افزایش امتیاز دوستی تا سقف ۱۰۰ (به همراه نشان جدید «هم‌پیمان ویژه»).
- **هالهٔ نوری تعاملی (Aura):** دکمهٔ «هاله» کنار «عینک» برای فعال کردن نورپردازی و مدارهای درخشان اطراف آواتار.
- **سنجاق کردن کارها و مدیریت پیشرفتهٔ چک‌لیست:** امکان سنجاق کردن (`Pin`) کارهای مهم در بالای تابلو، حذف تکی هر مورد از چک‌لیست، تیک زدن یا لغو تیک همهٔ موارد با یک کلیک و پاکسازی سریع موارد انجام‌شده.
- **هم‌فکری مستقیم با ریروکا دربارهٔ کارها:** دکمهٔ «مشورت با ریروکا» در هر کار که خلاصه و موارد باقی‌ماندهٔ همان کار را مستقیماً به بخش گفت‌وگو می‌فرستد.
- **جست‌وجو، مدیریت و خروجی در گفت‌وگو:** جست‌وجوی آنی در تاریخچهٔ پیام‌ها (با پشتیبانی از حروف و ارقام فارسی/عربی)، کپی یا حذف هر پیام به‌صورت مجزا و دریافت کل تاریخچهٔ گفت‌وگو با قالب Markdown.

## اجرای محلی

پروژه با Node.js ۲۲٫۱۸ به بالا در شاخهٔ ۲۲ یا Node.js ۲۴ کار می‌کند. پس از استخراج ZIP، از داخل پوشهٔ `riruka-tma` اجرا کن.

```sh
npm ci
npm run dev
```

مرورگر را روی [http://localhost:3000](http://localhost:3000) باز کن. استودیو، ابزارهای محلی، صف پیش‌نویس و گفت‌وگوی آزمایشی با env خالی کار می‌کنند.

## آزمون‌ها

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run test:integration
```
